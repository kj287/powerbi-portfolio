DASHBOARD DELIVERED · LOGISTICS REPORTING

Shipment & operational reporting

Challenge: Manual spreadsheet reporting required approximately four hours each cycle, limiting timely visibility.

Solution: Built a reusable Power BI reporting process supported by SQL validation and SQL Server–Snowflake data reconciliation.

Outcome: Reported preparation time reduced to approximately 30 minutes per cycle.

Tools: Power BI · SQL Server · Snowflake · Data validation

DASHBOARD DELIVERED · CUSTOMER ANALYTICS

APAC customer segmentation dashboard

Challenge: Understanding customer recency, frequency and monetary value across segments.

Solution: Designed Power BI customer analytics with RFM-based segmentation and six customer groups.

Outcome: Enabled clearer segment-level analysis to support retention and campaign decisions.

Tools: Power BI · Power Query · DAX · RFM modeling

DASHBOARD DELIVERED · FIELD OPERATIONS

Field activity & compliance dashboards

Challenge: Tracking field visits and activity performance across regions, territories and operational teams.

Solution: Combined six activity tables and designed region-, territory- and officer-level slicers and compliance measures.

Outcome: Gave users a consolidated view of activity trends against operational visit targets.

Tools: Power BI · CSV · Power Query · DAX

DATA DELIVERY · HIGH-VOLUME PROCESSING

Databricks pipeline & document automation

Challenge: Preparing large datasets and extracting structured invoice details from lengthy PDF files.

Solution: Used PySpark, SQL and Delta tables in a workflow handling 3M+ records and generating approximately 1,400 output files; separately worked on extraction from a 2,000-page invoice PDF.

Outcome: Established repeatable data-preparation and extraction steps for downstream reporting.

Tools: Azure Databricks · PySpark · SQL · Python
